How to use this panel
  • Select a business from the left sidebar to view/edit its Settings, Employees, Invoices, Clients, Products and Expenses.
  • Every table row can be edited as raw JSON (full control) or deleted.
  • Use "Disable Business" on a business's Overview tab to instantly block that owner + all their employees from logging into the app — no need to touch Firebase Authentication.
  • "Custom Path Explorer" lets you browse any Firestore collection path directly, in case something isn't covered by the tabs above.
